# UNtranslet Wallet

A starter monorepo for the UNtranslet Wallet payment experience, with separate Vite/React frontend and Express/Prisma backend workspaces.

## Getting started

1. Copy `.env.example` to `.env` and adjust values.
2. Install dependencies with `npm install` at the repository root.
3. Start both apps with `npm run dev`.

## Workspaces

- `frontend` — React, TypeScript, Vite, Tailwind-ready UI.
- `backend` — Express, TypeScript, Prisma-ready API.
- `docs` — architecture, database, and endpoint notes.
